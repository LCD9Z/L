### ⚠️ 核心问题：脚本的判定规则是纯点估计阈值，无任何统计检验

```python

    verdict = "B 年化超额两窗口均 > 2pp → 存在可实现 Alpha（样本内限定仍在）"
```

B 的超额刚过 2pp 线 → 脚本判"存在可实现 Alpha"。但加上统计量后：

→ **"点估计过线"被误读为"已证实"**。已**追加**统计口径限定（**不改原阈值规则**，避免事后移动门槛）：
判定文案现含"本判定应视为 **INCONCLUSIVE（未达统计显著）**，不得作为「已证实存在 Alpha」引用"。

> 口径：报的是**各臂自身收益**是否异于 0，**不是**超额是否异于 0（超额检验需逐期基准对齐，脚本未算）。

## 教训

1. **"只在结尾落盘"已连续两次造成损失**（09-19 与今日）。**长跑脚本必须分段落盘**，且
   `.partial` / `complete` 双文件设计比单文件更安全（部分文件不会被误当完整结果）。
2. **判定规则必须是统计检验，不能是点估计阈值**。阈值规则在点估计刚过线时会给出
   "已证实"的强结论，而置信区间可能宽达 ±37pp。
