**原始判断**：「创业板 ST 制度早已存在，但标记只有 2020+ → 覆盖缺口」

**核实后**：**创业板 2012-05 ~ 2020-08 期间【没有】ST 制度**，故标记从 2020 年起是**正确的**。

| 依据 | 内容 |
|------|------|
| **中国证监会**（2012-05-24） | 「改革了退市风险提示方式。**为避免存在退市风险的创业板公司与主板、中小企业板被实施 '*ST' 的公司相混同**…」→ 2012 年修订起创业板**不再使用 *ST 标记** |
| **深交所**（2020-08-07） | 「《交易特别规定》实施前，创业板风险警示股票（ST、*ST 股票）的价格涨跌幅限制比例为 5%」→ 2020-08-24 注册制改革**重新引入** |
| **数据验证** | 创业板 `is_st=1` 的行**全部在 2020-09 及之后**，改革日（2020-08-24）**之前 0 行** —— 与「改革后重新引入」完全吻合 |

### 缺陷 C 的撤回依据

**核实后**：**创业板 2012-05 ~ 2020-08 期间【没有】ST 制度**，故标记从 2020 年起是**正确的**。

| 依据 | 内容 |

| **数据验证** | 创业板 `is_st=1` 的行**全部在 2020-09 及之后**，改革日（2020-08-24）**之前 0 行** —— 与「改革后重新引入」完全吻合 |
