### 技术要点（创建专家的可复用经验）
- 流程：`init_expert.py <name> --type agent --path <专家目录>` → 填内容 →
  `validate_expert.py` → `register_expert.py`
- 专家目录固定：`$WORKBUDDY_CONFIG_DIR/plugins/marketplaces/my-experts/plugins`
- marketplace 索引在 `my-experts/.codebuddy-plugin/marketplace.json`
- **头像非校验必需**（4 个专家无头像也 validate 通过）；ImageGen 每张约 5-10 credits，
  故未擅自生成，已在项目 README 写明待办 + 推荐 prompt

  改用 Python `Path.write_text()` 成功。注册脚本本应自动写该标记但未写（env 有
  CODEBUDDY_SESSION_ID，脚本读取方式可能不同），已手动补齐。
