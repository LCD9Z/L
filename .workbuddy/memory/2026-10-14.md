### ⚠️ 踩坑：`.cmd` 里的中文注释会破坏批处理
首版 `run_backfill.cmd` 带**中文 `rem` 注释**（Write 工具输出 UTF-8，
而 cmd.exe 按 OEM/GBK 解码）→ **`cd /d` 行被破坏** →
python 在 `C:\Windows\system32` 下找 `scripts\run_xsrc_fetch.py`，
报 `can't open file ... [Errno 2]`（`LastTaskResult` 也异常）。

**修正**：`.cmd` 写成**纯 ASCII** + **绝对路径**（不依赖 `cd`）：
```bat
"%PY%" "%REPO%\scripts\run_xsrc_fetch.py" --codes ... --out ... --shards 2 --start 2003-01-01
```

**可复用教训**：**交给 cmd 的批处理文件一律不写非 ASCII 字符**（含注释）。
