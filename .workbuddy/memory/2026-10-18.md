#### CI：mypy 的「函数级作用域」陷阱

`main()` 里先有 `text, n = _rewrite_file(...)`（`n: int`），后有 `for n in todo`（`n: str`）

Python 变量无块作用域，**同一函数内复用短变量名会跨类型冲突**。修法：改用 `name`。
