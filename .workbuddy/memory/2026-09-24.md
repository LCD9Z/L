### 交付

**新增公共助手 `research_artifacts.py`**：

| 函数 | 作用 |
|------|------|
| `write_partial(out, payload, note=...)` | 写 `<out>.partial`，`complete: False` |
| `write_final(out, payload)` | 写正式 `<out>`，`complete: True` |
| `read_partial(out)` | 读回 partial（不存在/损坏 → `None`） |

**三个设计要点**：
1. **双文件语义**：**存在正式 `<out>` 即代表跑完**；`.partial` 可抢救且**不会被误当完整结果**。
2. **原子写**：`.tmp` + `os.replace`，不会读到半成品。
3. **失败不中断研究**：落盘异常只打印告警不抛出。

**接入 5 个长跑脚本**：`run_tail_exclusion_study` / `run_regime_overlay_study` /
`run_cost_model_check` / `run_contrarian_portfolio` / `run_concentration_study`
（后者 09-23 是内联实现，本次改为复用公共助手）。
