### E1 的运行细节（`run_daily.bat`）

```bat
rem 计划任务 TDXDaily（周一~周五 15:30），bat 位于 D:\hunhe\trunk\run_daily.bat
set PYTHONIOENCODING=utf-8                 # 必须：GBK 控制台无法编码告警字符
                                           # （screen.py U+26A0），曾致 10-15 崩溃
python -m tdx_native.run_daily            # 数据未更新自动跳过（计划任务友好）
python -m tdx_native.run_daily --force    # 强制重跑
rem 日志追加到 reports\daily\run.log（UTF-8）；退出码透传（防调度器误判成功）
```

前置条件：
1. 通达信数据在 `D:\new_tdx\vipdoc\{sh,sz,bj}\lday\*.day`，且**当日已收盘更新**
   （脚本自带未收盘保护 + 数据新鲜度检查）；
2. **下载/更新通达信期间禁跑**（.day 半截文件）；mtime 须距今 >5 分钟；
3. `data/gbbq_events.csv`（复权事件）、`data/names.csv`（名称表）在位；
4. 建议交易日 **15:05 后**运行（计划任务定 15:30 留余量）。

产物：`reports/daily/recommend_{date}.md/json`、导出的通达信自选股、
`tracking.csv` / `tracking_filled.csv`、到期卖出提醒、可选飞书推送。

## 六、故障排查速查

| 症状 | 先查 |
|---|---|
| 计划任务"跑了但没产物" | `reports/daily/run.log` 退出码；是否盘中被未收盘保护拦截 |
| run.log 出现 `UnicodeEncodeError: 'gbk'` | bat 须设 `PYTHONIOENCODING=utf-8`（`ed801ce` 已修；旧 Desktop 副本即崩于此） |
| run.log 报「名称表缺 N 只……未做 ST 剔除」 | `data/names.csv` 覆盖不足的数据维护问题（10-15 起出现的待办，非代码缺陷） |
| 回测结果异常好 | 通达信是否在下载中（半截 .day）；是否碰了 `min_rows=504` 数据集 |
| baostock 数据恰好 2000 行 | **静默截断**，须复核（`pit/baostock_guard.py`） |
| 腾讯量与通达信差 100 倍 | volume 单位分板块（sh688=股，其余=手），见 04 篇易踩点 |
| 飞书无推送 | token 过期（当前 21001 故障，需人工重新授权，见 07 篇 §六） |
