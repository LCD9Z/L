## 一、内部依赖（包间方向，均无环）

```
生产链主脉
  run_daily → daily_report → screen → day_reader / adjust / five_factor / gbbq_reader
  run_daily → backfill → (tracking.csv, 指数日历)
  run_daily → notify.feishu_notifier（可选降级）

研究链
  factors   : lab → (gate, registry, validation)；blind_test → ashare
  pit       : research_rows → trading_filter → event_master（integrity/universe_builder 独立）
  corporate : ingest → provider → actions
  fetch     : transport/common → quote/kline → news → cli
  track     : costs/schema → store → stats
  ashare    : universe → market（唯一内部边）
  validation: validation_suite → (performance, phase13_risk) + 根目录 data_quality
  console   : teams → display
  stage2 / alpha / regime / risk / reporting / runtime / router / tdx / phase62 / tushare_client
            : 包内独立或单向外依赖
```

**门面边界**（对外只许用门面，不许直依赖实现包）：
- `from data_fetcher import ...`（✅）而非 `fetch.*`（❌）
- `import tracking`（✅）而非 `track.*`（❌）

**零依赖孤岛**：`runtime/`（刻意不依赖项目内模块——防循环导入、供重型模块导入前读取）、
`ashare/`（纯计算）、`pit/`（纯函数）、`fetch/`、`track/`（纯标准库）。

## 四、外部服务依赖

| 服务 | 用途 | 失败策略 |
|---|---|---|
| 通达信行情服务器 | `fetch_names` 拉名称表 | 多 host 轮流（≤12），北交所取不到已登记 |
| 东财/腾讯行情 | `fetch/quote`、`fetch/kline` | 腾讯兜底东财；路由失败降级默认源 |
| baostock | 跨源验证 K 线 | **一页 2000 行+静默截断** → `n%2000==0` 必复核；日期分段规避 |
| 飞书 webhook/多维表格 | 每日推送、跟踪写表 | 不阻断主流程；超时+重试；⚠️ 当前 user token 过期（21001，见 07 篇） |
| LLM API（`llm_client.py`） | 历史多智能体框架 | 需 `llm_config.json`（不入库）；生产链已不依赖 |

## 五、本机环境约束（踩过的坑）

| 限制 | 表现 | 对策 |
|---|---|---|
| 前台命令 ~5 分钟 SIGTERM | 长回测中途无输出退出 | 每窗口一独立进程、各自落盘 |
| 后台任务 25–40 分钟静默死亡 | 进程消失无产物 | 拆小批次；不押注单次运行 |
| 宿主「安全删除守卫」 | 批量删临时文件被拦 | 不落临时文件；必要时 `os.replace()` |
| Bash 含 Windows cmdlet 名被拦 | "bypasses PowerShell security checks" | 改描述性表述或用 PowerShell |
| 通达信下载/更新期间 | .day 写到半截 | **禁跑回测**；确认 mtime 距今 >5 分钟 |
| git 本地 fetch 直读对方路径崩溃 | exit 0xC0000005 | 用 `git bundle` 中转（本次整合即用此法） |
