## 三、60 秒速览

```
生产链（每日）   通达信 .day → screen 五因子打分 → V1/V2 过滤 → Top20 候选
                 → tracking.csv → T+1/T+5/T+20 回填 → 卖出提醒 → 飞书推送
研究链（按需）   假设 → *_PREREG.md 预注册 → scripts/run_*.py → reports/*.json
                 → *_VERDICT.md 判定（负面结果同样归档）
正式入口         E1: python -m tdx_native.run_daily　E2: python run_ci.py
                 E3: python -m augment.cli（10-15 P0 登记，旁注层默认关）
固化配置         C20 分散 + V1 尾部剔除 + V2 跳空过滤 + 前复权 + ST 剔除
                 + 持有 20 交易日 + T+1 开盘建仓
铁律             不宣称 alpha ｜ 先预注册后实验 ｜ 负面结果归档 ｜ 数字须可追 JSON
```
