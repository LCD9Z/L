## 一、tdx_native 生产链（每日推荐系统）

### 1.1 主流程时序（`run_daily.run()` L315–422）

```
main() L426
 └─ run(vipdoc, top_n=20, out_dir="reports/daily", ...) L315
     1. 读配置 / 飞书 webhook（_read_webhook L293）
     2. 未收盘保护 guard_unfinished_session L50（盘中禁止跑）
     3. 数据新鲜度检查 _data_as_of L255 + _is_trading_day L262
        （数据未更新且非强制 → 自动跳过，计划任务友好）
     4. 完整性预检 screen.preflight L37（池子规模检查；
        ⚠️ 不检查".day 是否正在被写入"——下载期间禁跑，mtime 须>5 分钟）
     5. daily_report.build_report(...) L48 → 生成推荐
     6. 导出通达信自选股文件（_market_prefix L37 / _xueqiu_code L45）
     7. backfill.run(...) L138 → 回填跟踪收益
     8. 到期卖出提醒 _due_exits L64 → export_exits L101
     9. 可选飞书推送 feishu_push L180 / feishu_alert L136（卡片消息 _feishu_post L164）
```

### 1.2 选股核心（`screen.run()` L73–199）

```
run(vipdoc, top_n=20, exclude_ret20_top=0.0, ...)
 1. day_reader.scan_stocks L121 / scan_paths L145   扫描 sh/sz/bj 的 .day
 2. 截止日对齐 + 停牌过滤（尾部 bar 缺失判定）
 3. ST 剔除（day_reader.load_names L166 名称表）
 4. adjust.apply_qfq L68  前复权（qfq_factors L31 由 gbbq 事件算因子，
    event_factor L19 单事件因子；仅调 OHLC，amount/volume 不动）
 5. five_factor.compute_factors L27 → ret20/vol20/amihud20/loga20/maxret20/liq20
    （liq20 流动性门槛过滤在此）
 6. five_factor.composite_score L75 方向化综合分（pct_rank L58 横截面秩）
 7. V1 尾部剔除（exclude_ret20_top：剔除当日 ret20 最高 20%）
 8. Top-N 排序 → _fmt L161 → JSON 输出
```

## 四、易踩点（源码级）

1. `.day` 写入中读取会读到半截 → `preflight` 不查此项，跑前确认 mtime>5 分钟。
2. 腾讯 K 线 volume **分板块**：`sh688`=股，其余=手（×100）；判定必须用未缩放原始值
   +跨源裁决（曾犯循环论证，AGENTS.md §8 有全记录）。
3. baostock 一页=2000 行且分页失败**静默** → `n % 2000 == 0` 必须复核
   （`pit/baostock_guard.py`）。
4. `tdx_dataset_v2` 的 `min_rows=504` 是隐性次新股过滤——在其上做次新实验
   会得到虚假的"无差异"。
5. 前台命令约 5 分钟被 SIGTERM / 后台 25–40 分钟静默死亡（宿主限制）→
   长任务拆小批次、每批独立落盘。
