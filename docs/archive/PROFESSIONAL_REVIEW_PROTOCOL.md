# 专业评审委员会协议

本项目在原有“基本面/情绪/新闻/技术/看多/看空/交易/风控”之外，增加 7 个独立专业席位：

1. 量化研究员：未来函数、样本外、因子稳健性、成本、基准。
2. 基本面基金经理：盈利质量、现金流、估值、行业竞争。
3. A股资深交易员：T+1、涨跌停、停牌、可卖性、流动性、执行。
4. 市场微观结构专家：成交额、换手、冲击成本、封板/开板、异常交易。
5. 首席风险官：仓位、回撤、尾部、集中度、一票否决。
6. 数据与点时态审计师：来源、发布时间、复权、公司行动、幸存者偏差。
7. 事件与舆情研究员：公告/新闻真实性、直接相关性、时间有效性。

委员会不是简单平均分数，而是先找反证、再找共识；任一硬门槛失败时可以建议“暂缓/否决”。
