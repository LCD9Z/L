## 一、这是第一次真正跑通端到端实证

此前所有测试验证的都是**工程机制**（链路能否跑通、口径是否自洽、边界是否正确），
从未在真实历史数据上检验过策略表现。

本次首次完成完整链路：

```
原始 CSV(641MB)
  → 品种过滤（剔除 ETF/指数/可转债，9,438 → 5,584 只真实股票）
  → OHLC 清洗（剔除 113 行越界）
  → 抽样 1,500 只 + 每股 CSV + sha256 元数据
  → 构造 PIT 股票池（1,240 个交易日快照）
  → 过 professional_audit preflight 门禁
  → portfolio_backtest（真实撮合规则）
  → alpha_survival_lab（block bootstrap + 符号置换检验）
```

## 四、如何解读这个负结果

### 4.1 这是有价值的结论，不是失败

一个诚实的负结果比一个含糊的正结果有用得多。它直接回答了一个此前无人验证的问题：
**项目内置的基线策略能不能赚钱？答案是不能。**

### 4.2 ~~结论方向是稳健的~~（已撤回，见文首更正）

> ⚠️ 本节原有论证已被推翻。当时的推理是"幸存者偏差会让结果看起来更好，
> 而策略在此偏乐观数据上仍失败，故结论稳健"。
>
> **该推理忽略了抽样维度**：5 个窗口共享同一股票池。跨 4 个独立抽样后，
> 基线超额从 -41.91% 到 +8.14%（跨度 50pp），"稳定失败"不成立。
>
> 幸存者偏差的方向性论证本身仍然成立（偏差确实使结果偏乐观），
> 但它不足以支撑"结论稳健"—— 因为抽样噪声的幅度（50pp）远大于该偏差的影响。

### 4.2b 正确的表述

**在本次使用的股票池上**，基线策略跑输基准。但该结果**不可外推**：

- 更换随机抽样后，基线超额在 [-41.91%, +8.14%] 区间内变动
- 根因是策略持仓仅 5 只、单仓 25%，**抽样噪声主导结果**
- 因此本报告的所有数字应视为**该股票池上的观测**，而非策略的固有属性

### 4.3 统计上不显著 ≠ 策略没问题

注意 t = -1.19、p = 0.233，**超额收益在统计上并不显著**（样本 652 天，波动大）。
严格地说，数据只能支持"**未能证明存在 Alpha**"，而不是"证明了不存在 Alpha"。

但实务判断是清晰的：一个胜率 43%、回撤 44%、在上涨市里亏钱的策略，
没有理由投入实盘。

## 六、亏损机制分析

为理解策略为何失败，需看其信号构造（`walk_forward.score_history`）：

基准分 50，通过以下加分项达到阈值 70：

| 条件 | 加分 |
|------|------|
| 当日上涨 0~3% | +pct×2（最多 +6） |
| 当日上涨 >3% | 最多 +10 |
| 换手率 1~8% | +10 |
| 5 日趋势 +5~12% | +10 |
| 收盘价 ≥ 前 5 日最高价（突破） | +10 |
| 周期阶段加成 | +4 ~ +8 |

**即：策略要求「当日上涨 + 近期上涨 + 突破新高 + 换手活跃」才买入，
然后在 T+1 开盘买入、持有 5 日。**

这是一个**纯短期动量追高**策略。而 A 股存在显著的**短期反转效应** ——
短期涨幅居前的股票在随后数日倾向于回落。策略恰好系统性地买在这类位置上。

实测胜率 43.26%、盈亏比 0.971（`profit_factor`），与该机制解释一致。

**这不是实现 bug，而是策略假设本身与市场特征相悖。**

## 七、必须说明的局限

| 局限 | 对本次结论的影响 |
|------|-----------------|
| **幸存者偏差** | 使结果偏乐观 → 结论方向稳健 |
| **不复权价** | 除权跳空会制造假突破/假破位，**可能高估策略劣势**。但 A 股年化股息率约 1-2%，5 日持仓下影响有限，不足以解释 57pp 的差距 |
| 仅一个 2.6 年样本外窗口 | 未覆盖多种市场 regime |
| 800 只抽样股票池 | 已用等距抽样避免代码段偏差，但非全市场 |
| 无换手率/流通股本 | 未施加真实容量与流动性约束 |
| 仅测试了内置基线策略 | 结论**只针对该策略**，不能推广到项目其他因子模块 |

## 九、后续建议

### 若要继续验证策略

1. **补齐退市股数据** —— 第一优先级，缺失则所有收益数字都偏乐观
2. **补复权因子** —— 消除除权跳空对趋势因子的污染
3. **扩充到全市场 5,584 只**（需解决沙箱文件数限制）
4. **拉长样本外窗口至互不重叠** —— 当前 5 个窗口时间高度重叠，非独立样本
5. **预注册参数与评价指标** —— 避免事后挑选（本次未做任何参数寻优，即为避免此问题）

### 关于当前基线策略

**已定位失败机制**（见第六节）：该策略是纯短期动量追高，
与 A 股显著的短期反转效应相悖。**这不是可以靠调参解决的问题。**

因此明确建议：

- **不要**对阈值 / TopN / 持仓周期做网格搜索"救活"它 ——
  在同一批窗口上调参必然过拟合，得到曲线拟合而非 Alpha
- 若要改进，应先提出**有经济逻辑的假设**（例如反转而非动量、加入估值或质量约束），
  再在**独立的、互不重叠的**样本外窗口上检验
- 在补齐退市股与复权因子之前，任何改进的验证结果都**不足以支撑投资决策**
