审阅 H-CD 时我发现「6/6 含样本内窗口」这个问题。**同一把尺子量本项目，结论是**：

> **本项目全部 A/B 窗口（2023-07-03 / 2024-01-02 / 2024-07-01 / 2025-01-02 / 2025-07-01）

**不能回答「这个区间之外是否也更好」**。

**落地**：给 `SIX_ISLANDS_WIRING_REPORT.md` 与 `IMPACT_AND_CAPACITY_REPORT.md` 补口径声明（本次已改）。
**今后凡写多窗口 A/B，必须显式标注样本内/样本外。**

## 一、采纳并已落地

### A1 · 样本内/样本外显式标注（**采纳 · 已落地**）

见 §〇。**这是本次采纳里对本项目影响最大的一条**。

### A2 · 「用因子自身分布筛样本」= 构造性干预（**采纳 · 已登记**）

本项目存在**两处同类耦合**：

| 位置 | 做法 | 被干预的因子 |
|------|------|-------------|
| `--exclude-ret20-top 0.20`（**V1 尾部剔除**，T1 最优配置的一部分） | 剔除当日 `ret_20` **最高 20%** | **`ret_20` 自身** —— 直接截断其横截面 |
| `is_liquid(hist, min_avg_amount=1e8)` | 按 20 日均成交额筛 | **`log_amount_20`**（定义变量即成交额）· **`amihud_20`**（分母即成交额） |

**这不是理论担忧，H-CD 给了直接证据**：同一批数据、只换流动性门槛，
`amihud20` 的符号一致性在 **1 亿门槛下 1/6 · 中位数门槛下 0/6 · 无门槛下 6/6**。

**因此必须登记两条限定**：

1. **在 V1 / 流动性门槛下测得的因子 IC，与无门槛下测得的 IC 不可直接比较** ——
   两者是不同样本定义下的两个量
2. ⚠️ **`FACTOR_SUBSET_PREREG`（H-F4）的结论受此影响**：其 IC 层
   （`run_tdx_universe_ic.py`）内含 `liq20 < 1e8` 门槛。
   故「**不支持剔除 `amihud20`**」（ICIR 0.6069 < 0.6222）这一判定
   **是在 1 亿门槛下得到的** —— 而 H-CD 显示 amihud 的方向**恰恰最依赖这个门槛**。
   → **H-F4 的结论应加限定「仅在 1 亿流动性门槛下成立」**，不宜外推。

### A3 · 因子独立性：**本项目已有答案，但报告没引用**（**采纳 · 已引用**）

`STEP1_3_EXECUTION_REPORT.md` §九（498 只 / 514 截面）：

| 因子对 | 平均截面 Spearman |
|--------|------------------|
| `amihud20 ↔ loga20` | **−0.89** |
| `maxret20 ↔ vol20` | **+0.85** |
| `loga20 ↔ vol20` | +0.44 |
| `ret20 ↔ 其余` | ≤ 0.39 |

**结论（项目原文）**：**五因子实为约 3 个独立信号**（流动性族 / 波动族 / 反转族），
**等权确属重复计票**；但家族配权 IC 0.092731 ≈ 等权 IC 0.092656（差 0.0001）→ 冗余不损害排序质量。

→ **落地**：今后凡写「五因子」，须注明「**约 3 个独立信号**」，不得被读成 5 个独立证据。
工具已具备（`factors/factor_ic_lab.py`：`factor_rank_correlation` / `orthogonalize_panel` /
`run_orthogonal_ic_study`），无需新建。

### A4 · 报告惯例：方向一致必须**同时报显著性**（**采纳 · 已写入惯例**）

H-CD 审阅显示：`loga20` 在 W1 主口径下 IC = −0.0023、**t = −0.16**，
「符号对」被计为「方向一致」—— **这正是过度宽松的典型**。

→ **惯例**：本项目今后报「方向一致」时，必须**并列**「符号一致窗口数」与
「符号一致且 |t|≥2 的窗口数」两列。**符号对但 t 近零，应标为「口径依赖 / 无法判定」，不得计为一致。**

### A5 · 告警/判据阈值必须**可机械判定**（**部分采纳 · 本项目基本达标**）

H-CD 的「raw/adj 分歧 <5% 则告警」**无法无歧义评估**（未定义是哪个因子、逐窗口还是合并），
必然被事后解释。

**本项目自查**：现有守卫（`tests/`）与 `release_gate` 均为**布尔断言**，可机械判定 ✓。
**唯一需补**：`credential_scan.py` 与各阈值类判据，**今后新增阈值时须写明"对谁、怎么算、取最大还是逐项"**。

## 二、不采纳（附理由）

| 条目 | 为什么不采纳 |
|------|------------|
| **跨年代窗口划分（W1-W5, 2003-2017）** | 本项目数据源（`tdx_dataset_v2` / `v3`）**仅覆盖 2016 年起**（v2 含退市股自 2016）。做不了 2003-2017。→ 但**可引用** H-CD 结果（见 §三） |
| **股权分置改革子期拆分** | 同上，数据不覆盖 2005-2006 |
| **「幸存者偏差对 IC 不敏感」的否定** | 对 H-CD 成立（通达信原生不含退市股）。本项目 **v2 数据集含退市股（2016 起）**，该缺口**已部分解决**；`v3` 的退市覆盖情况**未核实** → 列为待办而非采纳 |
| **P3（无门槛）作为稳健性口径** | 本项目主口径本就带流动性门槛（与实盘一致）。引入无门槛口径会纳入不可交易样本，与项目「可交易性」纪律冲突。→ **仅作为诊断用途可选**（见 A2） |

## 三、借力：用 H-CD 的**完全样本外**结果支撑本项目（**新增**）

H-CD 的 **W1-W3（2003 / 2008 / 2013 起，各 5 年）完全落在本项目标定区间之外**。
我重算其三口径矩阵，**主口径（P2 median）下**：

| 因子 | W1 | W2 | W3 | 一致 |
|------|:--:|:--:|:--:|:--:|
| `ret20` | −0.0550 | −0.0543 | −0.0625 | **3/3** |
| `vol20` | −0.0329 | −0.0306 | −0.0547 | **3/3** |
| `loga20` | −0.0023 | −0.0197 | −0.0420 | **3/3** |
| `maxret20` | −0.0336 | −0.0359 | −0.0648 | **3/3** |
| `amihud20` | −0.0190 | −0.0007 | −0.0074 | 0/3 |

→ **本项目四个因子的方向，在 2003-2017 的完全样本外窗口上方向一致。**

⚠️ **但这只能作为「外部证据」，不能作为本项目自证** —— 理由：
① 数据源不同（H-CD 用通达信原生 `D:/new_tdx/vipdoc`，本项目用 `tdx_dataset_v2/v3`）
② 实现不同（H-CD 用 `run_tdx_universe_ic.py`，本项目用 `factors/factor_ic_lab.py`）
③ **窗口未在本项目事前登记**

→ **落地**：本项目结论可加一句「**方向有 2003-2017 的外部独立证据支持（引自 H-CD），
但属另一数据源与另一实现，不计入本项目样本外验证**」。
