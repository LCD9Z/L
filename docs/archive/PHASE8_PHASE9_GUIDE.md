# Phase 8 + Phase 9 使用说明

## Phase 8：行业强度
将历史时点行业映射作为 `dict` 传给 `rank_industries(data, industry_map, as_of=日期)`。

**重要：** 行业分类必须尽可能使用历史时点分类。不能用今天的行业归属直接回填历史，否则可能产生幸存者偏差或分类漂移。

输出包括：5日、20日、60日收益、综合强度、排名和百分位。

## Phase 9：回测验证
`run_portfolio_backtest.py` 现在自动输出 Phase 9 基础诊断：
- CAGR
- 年化波动率
- Sortino
- 交易策略总收益

如提供基准曲线，可调用 `evaluate_backtest(result, benchmark_curve=...)` 获取：
- 基准收益
- 超额收益

如提供历史市场状态 `regime_by_date`，还可得到：
- STRONG 分段表现
- RANGE 分段表现
- WEAK 分段表现

## 推荐研究流程
1. 使用历史股票池。
2. 使用历史时点行业分类。
3. 训练/调参区间与样本外验证区间严格分离。
4. 分别检查牛市、震荡市、弱市表现。
5. 对不同阈值、持有期、成本假设做敏感性分析，而不是只挑选单一最优参数。
6. 最终推送到飞书时，同时发送市场环境、行业排名、个股建议和风险提示。

> 回测结果不构成未来收益保证。
