# Phase 22: 真实数据 Alpha 生存实验协议

## 结论纪律
Phase 22 不允许凭模拟数据、当前股票池或未审计下载数据宣称 Alpha 存活。

## 必须提供
1. 可追溯价格数据及 SHA-256 manifest；
2. Point-in-Time 股票池；
3. 历史 ST/停复牌/退市状态；
4. 公司行为和复权口径；
5. 预先登记的样本外区间、交易规则、成本模型和基准；
6. 真实基准收益序列。

## 判定
数据审计失败 => INCONCLUSIVE；预注册被篡改 => 拒绝实验；任何预先声明的 Alpha Gate 未通过 => NOT_ESTABLISHED。

没有真实、完整、可追溯数据之前，本版本只能提供实验基础设施，不能诚实地宣称策略拥有稳定 Alpha。
