# Phase 32 — A股资金与事件数据层

## 目标
把“行情/技术”之外的 A 股特有信息变成可审计的结构化输入：资金流、龙虎榜、业绩预告/快报、解禁、股东交易、回购及其他公告事件。

## 核心原则
- **点时态优先**：没有公告/可用时间戳，不能进入历史截止日研究结论。
- **数据语义不扩大**：龙虎榜是交易行为记录，不自动解释为“主力建仓”；资金净流入不自动等于未来上涨。
- **事件与价格分离**：事件层提供事实和风险标签，交易层再决定如何使用。
- **A股交易约束优先**：T+1、停牌、涨跌停、板块涨跌幅和流动性仍是硬约束。
- **缺失即缺失**：没有数据就降级，不用模型生成数字。

## 已实现
1. `ashare_event_engine.py`：公告/业绩/解禁/减持/回购/龙虎榜事件归一化和 PIT 过滤。
2. `ashare_flow_engine.py`：资金流、龙虎榜的可复核统计特征。
3. `ashare_universe.py`：A 股全市场候选预筛接口，停牌/退市/不可交易风险硬否决。
4. `v3_data_bus.py`：预留事件/资金输入并统一进入 `DataBundle.events`。
5. `candidate_prefilter.py`：将事件风险标签加入 LLM 前置审查。

## 尚未宣称完成
本阶段**没有伪造“已经接入全市场实时龙虎榜/资金流”**。实际联网数据源必须在用户机器配置并通过数据质量/PIT 审计后才进入研究链路。
