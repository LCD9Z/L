# Phase 30 专业复核报告

## 结论
本轮不是简单“加几个 Agent”，而是把系统改成“事实层 → 独立分析 → 多专业压力测试 → 交易决策 → 风控”的结构。

## 七名专业人员的检查重点

### 1. 量化研究员
- 检查未来函数、样本外、基准、交易成本、滑点。
- 强制区分研究期与未来信息。
- 交易策略不能仅凭 LLM 评分平均值。

### 2. 基本面基金经理
- 检查收入/利润/现金流、ROE、负债、估值与行业竞争。
- 数据包没有财报字段时必须明确“数据未获取”。

### 3. A股资深交易员
- 检查 T+1、涨跌停、停牌、可卖性、成交额、换手率。
- 对涨停买不到、跌停卖不掉等情况，不允许回测模型假设“理论成交”。

### 4. 市场微观结构专家
- 检查成交额、换手、冲击成本、封板/开板、异常波动。
- 低流动性股票即使模型评分高，也可能被执行条件否决。

### 5. 首席风险官
- 检查仓位、最大回撤、尾部风险、集中度、组合相关性。
- 有权给出“暂缓/否决”，而不是被交易员强制覆盖。

### 6. 数据与点时态审计师
- 检查来源、发布时间、复权口径、公司行动、幸存者偏差。
- 历史研究时，没有发布时间的新闻默认不能证明在当时可获得。

### 7. 事件与舆情研究员
- 检查新闻是否直接涉及公司，而不是只因为关键词相似。
- 新闻发布时间必须早于研究时点；抓取时间不能冒充发布时间。

## 本轮自动化硬门槛
机器检查与 LLM 判断分离：
- 实时价格是否存在
- 行情时间是否存在
- K线数量
- 新闻数量
- 新闻发布时间覆盖率
- 成交额/换手率是否存在
- Crawl4AI 是否启用
- 历史研究是否设置 cutoff

## 当前仍需实盘环境完成的工作
1. 安装 Crawl4AI 并执行真实网页抓取。
2. 配置合法新闻/公告 URL 来源。
3. 接入可靠的 A股财务、资金流、公司行动、历史股票池数据。
4. 用真实历史数据运行长周期 walk-forward、分市场状态回测。
5. 做纸面交易后再考虑实盘。
