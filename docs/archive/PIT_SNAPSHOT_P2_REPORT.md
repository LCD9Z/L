## 三、⚠️ 两个**口径陷阱**（本轮的主要方法论产出）

### 陷阱 1：**价格复权口径不同 → 不能直接比 `pb`/`pe_ttm`**

| 侧 | 价格 |
|---|---|
| 本项目 v3 | **qfq 前复权**（锚定 2026-09-11） |
| baostock `adjustflag='3'` | **不复权** |

→ 直接比比率会把**复权因子**当成「源不一致」。
→ **正确做法：比「隐含分母」**：`close / pbMRQ` ↔ 我们的 `bps`；`close / peTTM` ↔ 我们的 `ttm_eps`。

### 陷阱 2：**「公告日 +1 年」不是我方新缺陷，是已处理的已知问题**

我方一度把「87.81% 的记录公告日滞后 >6 个月」当成新缺陷 ——
**核实后发现 `resolve_availability()` 的文档已明写**：

> 「`statutory_deadline` 法定披露截止日。**兜底**：公告日不可信（**典型是系统性偏移 +1 年**）……」

→ 模块**已有兜底**：公告日距法定截止日 >45 天即退回法定截止日。
**我判早了，已撤回。**（与 09-26、10-11、本日 09:2x 三次同类。）

**影响**：走兜底路径时我方**偏保守**（用法定截止日，而非真实公告日）——
这正是 §2.2 中 eps 离散度**主要来自我方偏晚**、而非 baostock 偏早的原因。

## 七、⚠️ 更正与新增发现（2026-10-12 晚，复核后补）

### 7.1 **撤回**：「688981/000001 的披露日缺失」是**我的误判**

我先前据此建议「补披露日覆盖率」。**复核后该前提不成立**：

```text
load_disclosures('D:/tdx_dataset_v3/disclosure_dates.jsonl')
  → 688981 2023-09-30 = 2023-11-10 · 2023-12-31 = 2024-03-29 · 2024-03-31 = 2024-05-10
  → 000001 2023-09-30 = 2023-10-25 · 2023-12-31 = 2024-03-15 · 2024-03-31 = 2024-04-20
```

**数据完整**。我之所以认为缺失，是**探针输出被 `| tail -30` 截断**，
只看到循环最后一支（600519）的三行 → **又一次「用不完整的证据下结论」**（本日第 5 次同类）。

**且 `pf.as_of('688981','2024-03-29')` 确实返回 2023-12-31、`basis=actual_disclosure`** ——
**我方 PIT 门槛工作正常。**

### 7.2 ⚠️ **真正的差异：A+H 公司的「首次公开」早于「A 股披露日」**

复核 688981（中芯国际，**A+H**）的实测时间线：

| 日期 | 事件 | 来源 |
|---|---|---|
| **2024-02-06** | **中芯国际发布 2023Q4/年度业绩**（官网新闻，上海） | smics.com 官方新闻 |
| **2024-02-07** | **baostock 隐含 TTM EPS 切换** 0.8077 → 0.6069 | 实测 |
| 2024-03-28/29 | A 股《2023 年年度报告》披露 | 东财 `actual_disclose` = 2024-03-29 |

→ **baostock 在「首次公开」的次一交易日就切换 —— 完全 PIT 正确，不是前视。**

**而我方**：`disclosure_dates.jsonl` 来自东财 `stock_yjbb_em`，记录的是 **A 股披露日** →
**对 A+H 公司系统性偏晚约 7 周** → 我方**错过了一段已公开的信息**（保守，非前视）。

### 7.3 对 §五 结论的修正

| 原表述 | 修正后 |
|---|---|
| 「我方 eps 偏晚」 | ✅ 方向正确 |
| 「原因是披露日**缺失**」 | ❌ **错** —— 原因是**披露日只有 A 股口径** |
| 「修法：补覆盖率」 | ❌ **无效** —— 数据不缺 |
| **正确修法** | **对 A+H 公司改用「首次公开日」**（港股业绩公告日），或**显式接受该保守性并登记** |

### 7.4 对 PIT 检验的**方法论**修正（重要）

我那次 PIT 检验把「**A 股披露日**」当作「首次公开日」——
**对 A+H 公司会把「baostock 正确、我方偏晚」误判成 `early`（疑似前视）**。
本次 24 只样本恰好**不含 A+H**，故 `early = 0` —— **结论样本依赖，不能外推**。

→ **检验器须补一条判据**：`early` 命中时，**先排除「该股是 A+H 且港股已先行公告」**，
才能定性为前视。**已记入待办。**
