## 〇、先明确：这三条不是「再挑错」

`CROSS_DECADE_AUDIT.md` 的 P0/P1 修订清单针对的是**判定书的措辞与推理**。
本 addendum 针对的是**另一类问题**：**判定书漏引了自己项目里已经存在的证据**，
以及**残留中间产物可能被误引用**。这类问题的特征是 ——
**不会让结论变错，但会让读者无法判断结论的可信度**。

## 一、`STEP1_3_EXECUTION_REPORT.md` §九 **已经回答了**审阅包 §七.3

**审阅包 §七.3 问**：「ret20/vol20/loga20/maxret20 四个因子彼此高度相关……
那『4 个因子一致』是不是其实只是『1 个因子（小市值/高波动）一致』？我的判定是否高估了独立性？」

**这条已经被回答过。** `STEP1_3_EXECUTION_REPORT.md` §九（498 只 / 514 个不重叠截面）给出：

| 因子对 | 秩相关 |
|------|------:|
| `amihud20 ↔ loga20` | **−0.89** |
| `maxret20 ↔ vol20` | **+0.85** |
| `loga20 ↔ vol20` | +0.44 |
| `ret20 ↔` 其余 | ≤ 0.39 |

**结论（原报告原话的实质）**：五因子实为**约 3 个独立信号**
（**流动性族** / **波动族** / **反转族**），**等权确属重复计票**；
但**家族配权 IC 0.092731 ≈ 等权 IC 0.092656（差 0.0001）** → 冗余**不损害排序质量**。

### 因此建议

1. **判定书应引用它**，而不是把独立性问题列为**开放疑虑**。
   正确写法示例：

   > 「四因子方向一致性可能部分来自共同因子（本项目 §九 已测：五因子实为约 3 个独立信号）。
   > 但家族配权与等权 IC 相差 0.0001 → 冗余不影响排序质量，故本判定按『族』读即可，
   > **不应读作四个独立证据**。」

2. **审阅包 §七.3 的措辞需下调一档**：不是「未知风险」，而是「**已知的、且已被量化**」。

3. ⚠️ **该文件在 `1.0` 侧也存在**（已核实）—— 说明它不是「另一分支的独有产物」，
   引用它**不需要跨环境**。

> **诚实补充**：我（审阅方）也独立提出了同一条（见 `CROSS_DECADE_AUDIT.md` §七.3 与
> `EXTERNAL_AUDIT_ADOPTION.md` §A3）。**两条独立路径得到同一结论**，
> 这反而加强了「应当引用它」的理由。

## 二、审阅包 §二 的「约 5,600 只」与产物不符

| 出处 | 数值 |
|------|------|
| 审阅包 §二（背景描述） | 「通达信原生日线，2000-01-04 ~ 2026-09-30，**约 5,600 只**」 |
| 产物 `reports/cross_decade/*.json` | `"stocks": 2000` |

**两者差 3,600 只（2.8 倍）。** 这不是笔误 —— 它直接影响**样本量可复现性**。

### 为什么重要

1. **`max-stocks` 未在事前登记** —— `CROSS_DECADE_PREREG.md` §五 没有该参数，
   而判定书自己把「2000 只抽样」列为**标定差异来源** → 说明它是**实质参数**。
   实质参数未登记，等于**事后有自由度**。
2. **审阅包与产物的口径不一致** —— 读者无法判断「5,600」是**全池规模**
   （即数据可用 5,600 只、实际抽样 2,000）还是**实际使用规模**。

### 建议

- 明确写为：「全池约 5,600 只；**本实验按 `max_stocks=2000` 抽样**（该参数**未事前登记**，
  列为局限）」—— 或把 `max_stocks` 补进 prereg 并说明为何取 2,000。
- 若 2,000 是**均匀抽样**（如每 N 只取 1），请写出抽样规则；否则读者无法重跑。

## 三、`reports/cross_decade/` 下**并存两个结论相反的文件**

```
reports/cross_decade/
├── VERDICT.json          ← 结论：方向稳健
├── VERDICT_partial.json  ← 结论：INCONCLUSIVE
└── W1.json … R.json · sample_sizes.json · verify_after_800.json
```

`VERDICT_partial.json` 的 `status = INCONCLUSIVE`，而 `VERDICT.json` 是「方向稳健」。
**两者同目录并存、文件名都像「最终判定」** → 存在**被误引用**的风险
（下一个人跑 `cat VERDICT*.json` 会同时拿到两个相反结论）。

### 建议

1. 把中间产物移入 `_intermediate/`（本项目已在别处采用该约定）：
   `reports/cross_decade/_intermediate/VERDICT_partial.json`
2. **或**改名为自解释形式：`VERDICT_partial_inconclusive_before_data_completion.json`
3. **并且**（这条更重要）：在判定书里加一节「**判定沿革**」，
   明写「**由 INCONCLUSIVE 变为方向稳健，原因是补齐了 X 数据 / 重跑了 Y**」。

> **为什么第 3 条最关键**：审阅时我无法从产物区分
> 「**因为数据补齐而改变**」（正当）与「**重跑到满意**」（学术不端）。
> 这不是指控 —— 是**证据链缺一环**。补上这一环，判定就无懈可击。
> 这也正是 `CROSS_DECADE_AUDIT.md` P0 第 3 项的内容。
