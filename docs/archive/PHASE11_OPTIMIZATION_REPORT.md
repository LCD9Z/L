# Phase 11 优化报告

本版本重点修复：
1. API 密钥从发布包中清空，并提供示例配置。
2. 新增 `.gitignore`，避免密钥和数据库误提交。
3. 新增 A 股交易规则模块，统一涨跌停比例和价格计算入口。
4. 组合回测改为按每只股票自身的下一交易日执行 T+1，持有期也按该股票交易日计算。
5. 新增最低平均成交额过滤，默认 20 日平均成交额不少于 1 亿元。
6. 新增基于流动性的动态滑点。
7. 期末不再强制把无法成交的跌停仓位当作真实卖出，仅进行市值计价。
8. 新增参数稳健性扫描工具与基础测试。

## 仍需外部数据支持的关键问题
- Point-in-Time 历史股票池
- 历史 ST 状态、停复牌状态
- 精确复权数据和公司行为
- 真实成交额与盘口级冲击成本

因此本项目仍建议先用于研究和模拟盘，不能仅凭历史回测直接投入实盘资金。
