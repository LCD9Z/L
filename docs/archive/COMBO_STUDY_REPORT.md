# 组合层研究：尾部剔除 × 持仓分散度（2026-09-26）

> **口径**：v3 数据集 / 300 只抽样 / **horizon=20**（由 `HORIZON_NET_EFFECT_REPORT.md`
> 得出 h=20 明显优于 h=5/10/40）/ 3 个窗口 / 净收益口径（含成本）/
> 超额对自建等权全A基准。**信号 / 阈值 / 成本模型 / 窗口全部不变**，
> 只改 `candidate_filter`（是否剔除尾部）与 `top_n`（持仓数）。
> **产物**：`reports/combo_study_h20.json`；脚本 `scripts/run_combo_study.py`。

## 一、为什么做这个

项目至今只有两个**稳健**的正向发现，且**从未联合测试**：

| 发现 | 证据 |
|------|------|
| **尾部剔除** | 配对 t = +8.35 / +3.62 / +2.52（三个独立口径全部显著，§7.13） |
| **提高分散度降低离散度** | 跨种子标准差 17.17 → 6.12（§7.17.1） |

前者提升**点估计**，后者降低**离散度** —— 直觉上互补。

## 三、四条判读

1. **首次出现正超额配置**：`C5_V2`（h=20 + 尾部剔除）**均值 +4.96%，2/3 窗口为正**。
   这是项目至今**唯一**净超均为正的配置。
2. **⚠️ 但 `C5_V2` 的离散度最大**（标准差 9.69、区间跨度 18.35pp）——
   **它的正均值恰恰是最不可靠的**。单看 3 个窗口，`+4.96%` 与 `0` 无法区分。
3. **分散度单独用不足以转正**（`C20_V0` −2.96%），
   **且与尾部剔除是负交互**：`C20_V2`（−6.00%）比 `C5_V2`（+4.96%）**差 11pp**。
   → 「尾部剔除 + 分散度」**不是互补，而是相互抵消**，与事前直觉相反。
4. **分散度降低离散度的结论被再次印证**：
   `C20_V2`/`C30_V2` 的标准差仅 **1.36~1.52**（vs `C5_V2` 的 9.69，**降 6~7 倍**）。
   但**代价是均值更差** —— 这是明确的**精度 vs 均值权衡**。

## 四、⚠️ 必须随结论声明的限制

| 限制 | 说明 |
|------|------|
| **窗口只有 3 个** | 自由度极低，**本报告不输出显著性判定**。3 个窗口的均值不构成证据 |
| **样本 300 只** | 非全池；与既有 400 只研究不完全可比 |
| **`C5_V2` 的 +4.96% 不可作为结论** | 标准差 9.69 大于均值本身；`+4.96%` 与 `0` 无法区分 |
| **负交互的机制未查明** | 为何分散度抵消尾部剔除的收益，**属推断而非已测量**。可能方向：分散化把组合拉近基准，稀释了"避开尾部"的收益 |
| **h=20 本身未确立** | `HORIZON_NET_EFFECT_REPORT.md` 已声明：h=20 优于 h=5 的**方向**很可能真实，但"最优=20 日"不能由 3 窗口确立 |
| **探索性** | 未做事前登记；组合为事前指定的互补假设（非扫参），但仍属探索 |

## 六、下一步（未执行）

**若要确立 `C5_V2` 的 +4.96%**，唯一路径是**增加独立窗口数**。

## 八、⚠️ 修复「换手率分项静默失效」后的重跑（2026-09-26 晚）

### 8.2 四条判读

1. **修复的影响集中在 5 股组合**：`C5_V0` +12.67pp、`C5_V2` +4.35pp；
   而 `C20`/`C30` 几乎不变（−0.32 ~ +0.51pp）。
   **原因**：候选池扩大对"只取 top 5"影响最大；取 top 20/30 时本来就有足够候选。
2. **尾部剔除在修复后仍有效**：`C5_V2` 比 `C5_V0` 高 **+4.10pp**。
3. **分散度仍然拖累**：`C20_V0`（−3.28）低于 `C5_V0`（+5.21）。
4. **负交互仍然存在**：`C20_V2`（−5.49）比 `C5_V2`（+9.31）**差 14.80pp** ——
   与修复前（差 11pp）**同向**，故这不是修复造成的假象。

### 8.3 当前最佳配置

**`C5_V2`（h=20 + 尾部剔除）= +9.31%，2/3 窗口为正**。

⚠️ **但其标准差 12.42 仍大于均值** → **+9.31% 与 0 无法区分，不构成 Alpha 结论**。

**精度 vs 均值的权衡依旧清晰**：`C30_V2` 的 sd 仅 2.22（比 `C5_V2` 低 5.6 倍），
但均值为 −5.51%。
