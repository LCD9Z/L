# Phase 36 — A股因子验证实验台

## 本阶段完成

新增 `factor_validation.py`，建立轻量、无第三方依赖的截面因子验证器：

- 严格按股票代码分组、按交易日排序
- 因子使用 `t` 日观测值
- 收益只使用 `t+1 / t+3 / t+5 / t+10 / t+20` 之后的收盘价
- 输出 IC、RankIC、ICIR、RankICIR、IC 正向比例
- 输出 Top 20% vs Bottom 20% 的平均收益差和胜率
- 数据不足时返回 `None`，不制造统计结果
- 适合 8GB 机器的轻量批处理

## 为什么现在做这一层

v3.5 的 Stage-2 Alpha 目前仍是启发式权重。下一步不能继续“凭经验调权重”，而应该先让每个候选信号接受独立验证，再决定：

1. 保留
2. 降权
3. 删除
4. 仅在特定市场状态使用

这也是从“工程可运行”进入“真实 Alpha 研究”的关键一步。

## 当前边界

本阶段**没有声称任何真实 Alpha**。项目包当前没有经过严格 PIT/企业行动/历史股票池审计的完整历史数据，因此测试只验证计算逻辑，不把合成数据当作市场结果。

接入真实数据后，推荐先跑：

- T+1、T+3、T+5、T+10、T+20
- 全A截面
- 市值/行业中性版本
- 牛/震荡/熊市场状态切片
- Stage-1 vs Stage-1+Stage-2 增量比较
- 成本、换手、容量敏感性
- Walk-Forward OOS

## 验证结果

- 全测试：**90 passed**
- `compileall`：**PASS**
- 新增因子验证测试：通过
