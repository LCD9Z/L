# Phase 21 · 真实 Alpha 生存实验协议

## 当前诚实状态
本项目目前**没有打包足以支持最终 Alpha 结论的完整真实 A 股 Point-in-Time 长期历史数据集**。因此，Phase 21 默认结论必须是 `INCONCLUSIVE`，直到真实数据实验完成；任何代码测试通过都不得替代投资实证。

## 预注册实验门槛
1. 至少 252 个完全样本外交易期；
2. 每个实验必须对齐策略和基准收益；
3. 超额收益均值为正；
4. Block Bootstrap 95% 区间下界 > 0；
5. 正态近似检验与符号随机化检验均 p < 0.05；
6. 预先声明的所有独立样本外窗口均须通过；
7. 至少覆盖预先指定的多个基准（建议沪深300/中证500/中证1000，以及策略股票池匹配基准）；
8. 单独保存数据版本、生成时间、发布日期/可得时间字段。

## 禁止事项
- 用当前股票池冒充历史股票池；
- 用事后修订数据冒充当时可得数据；
- 失败窗口删除后再报告成功结果；
- 根据最终样本外结果继续调参；
- 将统计显著性宣传为未来收益保证。

## 当前下一步
接入合法、可追溯的真实历史数据后，运行预注册窗口，并把原始数据哈希、实验配置和完整失败/成功结果一并保存。
